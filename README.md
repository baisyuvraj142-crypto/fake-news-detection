## 📌 Project Overview

This project is an end-to-end Machine Learning and Natural Language Processing (NLP) web application that classifies news articles and headlines as **REAL** or **FAKE**. Built strictly using classical Machine Learning algorithms (Logistic Regression, Multinomial Naive Bayes, and Passive Aggressive Classifier) combined with TF-IDF vectorization and NLTK text normalization.

### 🌟 Key Highlights
- **100% Classical & Explainable ML:** No black-box deep learning or external internet fact-checking required.
- **Explainability (FR-21):** Extracts and displays the **top 5 words** that influenced the model's decision using Logistic Regression coefficients.
- **Data-Leakage Prevention (FR-5):** Removes source giveaways (such as `"CITY (Reuters) -"` prefixes and `"Reuters"` mentions) and ignores metadata like dates and subjects.
- **Model Comparison:** Automatically benchmarks 3 candidate algorithms on a stratified 80/20 train/test split and deploys the highest F1-score model.
- **Interactive UI & REST API:** Responsive Bootstrap 5 interface with real-time word counting, sample pre-fills, and a `/api/predict` JSON endpoint.

## 📊 Dataset Setup & Training

### Using the Kaggle ISOT Dataset (Recommended for Viva)
1. Download the **Fake and Real News Dataset** from Kaggle:  
   🔗 [Kaggle Fake and Real News Dataset (ISOT)](https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset)
2. Extract and place `Fake.csv` and `True.csv` inside the `data/` folder:
   - `data/Fake.csv`
   - `data/True.csv`

### Starter / Seed Dataset
If you do not have the Kaggle files immediately available, the project comes pre-configured with a generator:
```bash
python src/setup_dataset.py
```

### Train and Evaluate the Models
Run the training pipeline:
```bash
python src/train.py
```
This script will:
1. Load and clean the CSV datasets.
2. Strip data-leakage markers (`Reuters`, URLs, punctuation).
3. Extract unigram + bigram TF-IDF features (`max_features=5000`).
4. Train **Logistic Regression**, **Multinomial Naive Bayes**, and **Passive Aggressive Classifier**.
5. Compare their accuracy, precision, recall, and F1-score on a stratified 20% test split.
6. Save the best model to `models/model.pkl`, metrics to `models/metrics.json`, and the confusion matrix chart to `static/confusion_matrix.png`.

## 📡 REST API Documentation

The web app includes a built-in JSON REST API:

### Endpoint: `POST /api/predict`
- **Headers:** `Content-Type: application/json`
- **Request Body:**
```json
{
  "text": "The United States Senate approved a sweeping infrastructure package following weeks of bipartisan negotiations. Lawmakers voted in favor of allocating federal funding for highway repairs, public transit upgrades, bridge restorations, and clean drinking water initiatives across several states."
}
```

- **Successful Response (`HTTP 200`):**
```json
{
  "label": "REAL",
  "confidence": 76.98,
  "top_words": ["funding", "federal", "infrastructure", "upgrade", "clean"]
}
```

- **Validation Error (`HTTP 400`):**
```json
{
  "error": "Input text has only 4 word(s). Please enter at least 20 words for an accurate and reliable prediction."
}
```

## 🎓 Viva Quick-Reference Explanation (For Faculty Presentation)

| File / Component | What it does & Why it was designed this way |
| :--- | :--- |
| **`src/preprocess.py`** | Implements `clean_text()` to lowercase text, remove regex-based URLs, HTML tags, punctuation, and digits. Filters English stopwords using NLTK and applies `WordNetLemmatizer` to reduce words to root lemmas. Ensures identical preprocessing in training and inference. |
| **`src/train.py`** | Merges `True.csv` and `Fake.csv`, prevents data leakage by removing source identifiers, fits a `TfidfVectorizer(max_features=5000, ngram_range=(1,2))`, trains 3 models, benchmarks their F1-scores, and serializes the winning model and confusion matrix. |
| **`src/predict.py`** | Loads pickled artifacts once into memory for fast inference (<2 seconds). Enforces a 20-word minimum threshold (FR-22) and uses Logistic Regression coefficient weights multiplied by TF-IDF scores to highlight the top 5 influential words. |
| **`app.py`** | Lightweight Flask controller handling web routing, error catching without crashing (NFR-4), and exposing both Jinja2 templates and a REST API. |
| **`tests/test_basic.py`** | Contains automated Pytest test cases verifying cleaning logic, validation errors, and end-to-end API endpoints. |

## ⚠️ System Limitations & Future Work

1. **Linguistic Style vs. Live Fact-Checking:** The model evaluates stylistic phrasing, sensationalism, and vocabulary patterns. It does not check live databases to verify facts.
2. **Domain/Time Period:** Trained primarily on modern English general and political news.
3. **Future Enhancements:**
   - Word embeddings or fine-tuned DistilBERT / RoBERTa models.
   - Chrome browser extension for one-click webpage verification.
   - Multilingual support (e.g. Hindi, regional languages).
